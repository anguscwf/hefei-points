- `release`：生产 API 可用，但新增监护开通入口仍不可发现，生产功能门继续默认关闭。

### 法律发布

- `LEGAL_PUBLIC_ORIGIN` 必须是规范化的精确 HTTPS origin，例如合成测试使用 `https://example.invalid`，生产值须经正式发布审查确认。
- 数据库 `legal_text_versions.public_url` 和 `GUARDIAN_RELATION_DECLARATION_PUBLIC_URL` 必须按固定叶子生成；旧的任意 HTTPS URL 不再被接受。
- 正式页面内容、不可变发布、重定向、CSP、微信业务域名、客服/投诉联系方式和真机加载尚未验收，不能因为代码 allowlist 已完成就开启生产授权。

### 普通行权恢复

- 客户端只有 operation 对账返回 `completed`、本人详情严格匹配、且本地 marker 清理成功后，才可创建下一次普通行权请求。
- `not_found` 不代表客户端可以换键，因为 POST 可能尚未到达可查询的持久边界；当前没有经产品批准的服务端放弃协议，所以继续 fail closed。
- 授权撤回、删除、终止、既有请求详情和已授权导出等安全/法定入口的功能门语义保持不变；未解决的普通行权 marker 不得封死授权撤回。
