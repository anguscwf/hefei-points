## 本次功能范围

1. 新增 `npm run prepare:synthetic-data-root`，只在完整 S12 synthetic 环境通过、候选根不存在、批准父目录精确等于候选根现存真实父目录，且 `SYNTHETIC_DATA_ROOT_PREPARE_ACK` 逐字等于 `prepare-new-empty-synthetic-root-v1` 时继续。
2. prepare 除 `--help` 外不接受 CLI 参数。成功路径只排他创建候选根、唯一空 `data` 子目录和精确 marker；在关键阶段反复核对配置指纹、批准父目录身份、根/子目录身份、目录条目和 marker 普通单链接字节。
3. prepare 不创建或打开 SQLite，不创建 Token secret，不启动子进程、服务或网络连接。成功输出不包含明文 origin、AppID、AppSecret 或绝对路径。
4. prepare 在中断或失败后不执行递归自动清理。任何已经出现的部分根均视为不可信残根；再次 prepare 必须以 `ROOT_ALREADY_EXISTS` 拒绝，禁止覆盖、补写、接管或自动删除。
5. 新增 `npm run verify:synthetic-data-root`，同样除 `--help` 外不接受 CLI 参数，只从当前进程读取完整显式 S12 配置和批准父目录；不要求 prepare 专用确认。
6. verify 连续执行两轮只读物理快照，复核批准父目录、根、`data`、marker、真实路径、设备/inode、链接数、模式、大小、时间元数据、精确目录条目、允许的数据文件集和 marker 摘要。任一快照发现不安全或两轮快照捕获到配置、身份、元数据或内容漂移时都 fail closed；同权限写入者在两次观察之间修改后恢复的瞬态竞态仍依赖外部 ACL/所有权硬门。
7. verify 只返回脱敏 schema 1 `synthetic-data-root-readiness` 结果。`configuration` 只证明配置和 marker 形态；`filesystem` 只报告摘要、条目数量与固定运行文件是否存在，不包含绝对路径或文件正文。
8. schema 1 中 AppID/开发者/AppSecret、request/business domain、DNS/TLS、OS 账号、ACL/所有者、磁盘/备份、数据库内容、基础设施、法律记录和生产根隔离均保持外部未验证；`operations` 明确本命令没有部署、打开数据库、联网、启动服务/子进程、调用 DevTools、preview/upload 或验证成人 smoke/HUKS。`productionChildGate` 只说明本命令未验证部署状态、未尝试改门。这些 `false` 不得手改为 `true`，也不得解释为对应外部硬门已经通过。
9. CLI 错误只输出稳定错误码；不回显输入值、本机路径、marker 正文、数据库内容或内部异常堆栈。详细操作与残根处置见 `docs/runbooks/受控-synthetic-数据根准备与核验.md`。

## `external=false` 的准确含义

- `appIdProvisioningVerified=false`：没有核验 AppID 已在平台开通。
- `developerAuthorizationVerified=false`：没有核验当前开发者账号和权限。
- `appSecretIndependenceVerified=false`：没有核验 AppSecret 的来源、托管、轮换或与生产隔离。
- `requestDomainVerified=false` / `businessDomainVerified=false`：没有核验平台后台中的两类域名配置。
- `dnsVerified=false` / `tlsVerified=false`：没有执行或核验 DNS、证书链、协议配置和实际 TLS 行为。
- `osAccountVerified=false`：没有核验专用 OS 账号存在或服务实际运行身份。
- `aclVerified=false` / `ownerVerified=false`：没有核验平台 ACL、继承规则、有效主体、获批所有者或最小权限。
- `diskIsolationVerified=false` / `backupIsolationVerified=false`：没有核验物理卷、快照、复制、备份、恢复源或到期清理。
- `databaseContentVerified=false`：不打开 SQLite，也不检查数据库内容或来源；不表示数据库为空或只含合成数据。
- `infrastructureConnectivityVerified=false`：没有核验端口、代理、边缘或基础设施实际连通。
- `legalRecordsVerified=false`：没有核验法律页面、版本、摘要、重定向或 CSP 的外部发布状态。
- `productionRootIsolationVerified=false`：只检查候选路径形态，未读取或识别真实生产数据根；不表示已经由外部证据证明物理隔离。

`operations` 中部署、数据库、网络、服务、子进程、DevTools、preview/upload、成人 smoke 与 HUKS/AssetStore 字段全部为 `false`，只表示本命令没有执行对应动作或验证；不证明其他会话或历史操作从未执行。`productionChildGate.deployedStateVerified=false` 表示没有读取部署现场，`changeAttempted=false` 只表示没有尝试改门；二者都不证明现场儿童门的实际值。
