# ADR-0002：敏感数据与本地构建材料边界

- 状态：已接受
- 日期：2026-08-20
- 决策人：安总

## 背景

项目工作区同时包含源码、家庭运行数据、数据库备份、日志、小程序私有配置，以及 HarmonyOS 本机签名配置和发布产物。历史上父仓曾跟踪其中部分文件，继续依赖人工挑选存在较高误提交风险。

## 决定

- 生产/开发运行数据、数据库、备份和日志一律留在 Git 外。
- HarmonyOS 根 `build-profile.json5` 视为本机秘密配置，始终忽略；仓库只允许无凭据的示例配置。
- `.p12`、`.csr`、`.cer`、`.p7b`、密钥库和 `.app`/`.hap` 等发布产物一律忽略。
- 微信 `project.private.config.json`、环境变量和本地助手记忆不进入 canonical 历史。
- 测试和文档只使用合成数据；秘密扫描发现命中时不得继续提交。

## 影响

- 新环境需要自行创建本地数据目录、私有配置和签名配置。
- Git 克隆本身不能恢复生产数据或发布凭据，这是刻意的安全边界。
- 备份、密钥轮换和灾难恢复由受控的外部流程负责，不能依赖源码仓库。
